## 1. 实操案例一

​	正在维护一个CentOS Stream 9服务器，需要定期检查系统的日志文件。今天的任务是查看最近的日志条目，将日志文件移动到指定的备份目录，并确认移动后的文件结构。

任务说明：

```powershell
1- 导航到日志目录：
	导航到/var/log/目录,存储都是一些日志文件信息
2- 查看日志文件：
	使用ls命令列出目录中的日志文件。
	日志文件名为dnf.log，查看该文件的前100行日志条目。
3- 移动日志文件：
	将dnf.log文件移动到/var/log/backup目录（如果backup目录不存在，请先使用创建它）。
4- 确认文件结构：
	使用cd命令导航到/var/log/backup目录。
	使用ls命令确认dnf.log文件已经成功移动到此目录。
	

涉及的技术点： cd、pwd、ls、mkdir、head、mv
```





## 2. 案例实操二

说明： 搭建一个简单的项目目录结构并进行文件管理

需求一：**创建目录结构：**

- 在当前目录下，创建一个名为 `my_project` 的主目录。
- 在 my_project中创建以下子目录：
  - `src`
  - `docs`
  - `assets`
- 使用 `ls` 验证目录结构是否正确。

需求二：**创建文件并编辑内容：**

- 在 `src` 中使用 `touch` 创建一个名为 `main.py` 的文件。

- 在 `docs`中使用 `vi` 或 `vim` 创建一个名为 `README.md` 的文件，并写入以下内容：

  ```
  # My Project
  This is a simple project setup.
  ```

- 在 `assets` 中创建一个名为 `logo.txt` 的文件，并将文本 `Project Logo Placeholder` 写入文件。

需求三：**查看和管理文件内容：**

- 使用 `cat` 显示 `README.md` 的内容。
- 使用 `less` 或 `more` 查看 `logo.txt` 的内容。

需求四：**修改文件：**

- 将 `logo.txt` 移动到 `src` 目录中。
- 复制 `README.md` 到 `src` 目录中，并重命名为 `README_COPY.md`。

需求五：**验证：**

- 使用 `ls` 和 `pwd` 验证当前目录结构和文件位置是否正确。



## 3. 案例实操三

说明：文件传输与压缩管理

需求一：**文件准备：**

- 在主目录中创建一个名为 `test_data` 的目录。
- 在 `test_data`中创建以下三个文件，并使用 `touch`命令初始化：
  - `file1.txt`
  - `file2.txt`
  - `file3.txt`
- 每个文件写入不同的简单内容（例如，文件名作为内容）。

需求二：**压缩和解压缩：**

- 将 `test_data` 目录打包为 `test_data.tar`
- 将 `test_data` 目录打包并压缩为 `test_data.tar.gz`
- 将 `test_data.tar.gz` 解压缩家目录下，并验证文件是否完整

需求三：**文件上传和下载：**

- 将 `test_data.tar.gz` 下载到 本地电脑上
- 将 `test_data.tar.gz` 上传到 服务器的/tmp目录下

需求四：**清理无用文件：**

- 删除 `test_data` 目录的内容，确保主目录整洁。
- 删除 `/tmp` 中的 `test_data.tar.gz` 文件。
- 删除家目录下的解压后的内容
